DAILYKIT — STATIC WEBSITE STARTER PACKAGE

Includes:
index.html (tools homepage), about/contact/privacy/terms pages, guides and three guide articles, style.css, site.js, logo.svg, robots.txt, sitemap.xml.

BEFORE PUBLIC LAUNCH:
- Replace YOUR-DOMAIN.com everywhere (index canonical/JSON-LD, robots.txt, sitemap.xml).
- Replace YOUR-EMAIL@example.com with your real email in contact, privacy, terms.
- Replace publication-date placeholders.
- Read and edit privacy policy and terms to reflect what you ACTUALLY deploy (hosting logs, cookies, consent, analytics, AdSense etc.). These templates are not legal advice.
- If deploying ads, configure consent/privacy disclosures as applicable for your visitors and jurisdiction. Do not add a fake ads.txt. After AdSense provides your publisher ID, create /ads.txt using the exact format shown in your AdSense account.
- Do not place ads in deceptive layouts or near interactive tool controls.
- Test each tool and every link on phone and desktop before applying.

GITHUB:
Upload all package contents into repository root. index.html should be at root.

VERCEL:
Import repository as a static project. No build command needed for plain static files. Deploy.

SEARCH CONSOLE:
Verify your domain/property, inspect your homepage, request indexing and submit sitemap.xml. Indexing and ranking are not guaranteed. Don't submit repeatedly; fix quality or crawl issues first.

ADSENSE:
Approval is not guaranteed. Review Google publisher policies and eligibility. Maintain original useful content, working navigation, clear privacy/contact/about pages, accessible design and avoid thin/duplicated content. This package is a starter, not an approval guarantee.
