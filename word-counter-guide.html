How to count words and characters

Word counts are useful for assignments, articles, descriptions, messages and application forms. Character counts matter when a platform limits the length of a title, caption or post.

What is a word count?

A word count estimates how many words appear in a text. Different software may treat hyphenated terms, contractions, numbers and punctuation differently, so counts can vary slightly between tools.

What is a character count?

Character count measures the length of text. Some systems include spaces and punctuation; others provide a count excluding spaces. DailyKit displays the total characters in the text you enter, including spaces.

How to use the text tool

  1. Open the DailyKit homepage.
  2. Paste or type your text into the Word & Character Counter.
  3. Review the live word, character, sentence and reading-time estimate.
  4. Use the text conversion buttons if you need a different letter case or spacing.

Reading-time estimates

Reading time is only an estimate based on a typical reading pace. Actual time depends on the reader, language, complexity and formatting.

For important submissions, check the counting rules used by the destination platform.
